# Sharing and installation

Public repository: https://github.com/lonnrek96/video-understanding

Read the repository [English README](https://github.com/lonnrek96/video-understanding#readme) or [Chinese README](https://github.com/lonnrek96/video-understanding/blob/main/README.zh-CN.md) for installation and examples. The repo includes a dependency list and an installer that refuses to overwrite an existing skill.

For manual installation, copy this entire skill directory as `video-understanding` into your host's skills directory, then follow [runtime setup](setup.md). Automatic invocation is enabled for supporting hosts; it is not proof that a host selected the skill in a particular conversation.

Share the skill, not downloaded videos, transcripts, manifests, cookies, model caches or private run output.
