# Sharing and installation

Public repository: https://github.com/lonnrek96/all-video-mcp

Read the repository [English README](https://github.com/lonnrek96/all-video-mcp#readme) or [Chinese README](https://github.com/lonnrek96/all-video-mcp/blob/main/README.zh-CN.md) for installation and examples. The repo includes a dependency list and an installer that refuses to overwrite an existing skill.

For manual installation, copy this entire skill directory as `all-video-mcp` into your host's skills directory, then follow [runtime setup](setup.md). Automatic invocation is enabled for supporting hosts; it is not proof that a host selected the skill in a particular conversation.

Share the skill, not downloaded videos, transcripts, manifests, cookies, model caches or private run output. The original code/instructions use MIT; dependencies and source media retain their own terms. See [validation](validation.md) for tested and unverified coverage.
